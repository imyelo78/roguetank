# 17 版说明

**这一版最重要的一句话：你要的「一款豹式」，之前其实没真正生效。**

数据层改了、选车界面也只剩一张卡，但玩家开出去的车一直是**敌人用的极简模型**。
所以从你的视角看，就是"让你改一款坦克，你根本没做"——你的判断没错。

## 一、豹式为什么看着没变：模型表不认 `panther`

`Tank.js` 里的模型表长这样：

```js
const BUILDERS = {
  balanced: buildBalanced,
  light: buildLight,
  heavy: buildHeavy,
  hunter: buildHunter,
};
```

而合并车体后，客户端传的是 `'panther'`。`BUILDERS['panther']` 是 `undefined`，
于是落到了这一行：

```js
const builder = BUILDERS[chassisId] || buildStandard;   // ← 静默降级
```

`buildStandard` 是**敌人用的低模**。结果：

| | 零件数 |
| --- | --- |
| 豹式（buildBalanced，真正的模型） | **45 个 mesh** |
| 敌人低模（buildStandard） | 12 个 mesh |

没有侧裙、没有炮盾、没有车长指挥塔、没有高射机枪、没有天线、没有烟幕弹发射器、
没有探照灯、没有炮管抽气装置。配色是对的（所以看着"像那么回事"），但轮廓完全不是豹式。

**这是最伤的一种 bug**：所有测试都绿、数值全对、日志无报错，只有玩家能看出来不对。

### 修复

```js
const BUILDERS = { panther: buildBalanced };

// 传了 chassis = 玩家车（含老 id），一律归一化成豹式；没传 = 敌人
const chassisId = opts.chassis ? normalizeChassisId(opts.chassis) : 'standard';

// 兜底是豹式，不是 buildStandard
const builder = chassisId === 'standard'
  ? buildStandard
  : (BUILDERS[chassisId] || BUILDERS.panther);
```

同时**删掉了** `buildLight / buildHeavy / buildHunter` 三个函数（198 行）。
留着它们就是留着一个"以后又会有人画出第二种车"的入口。

实测（浏览器里数 mesh）：

```
自己（豹式）     45 mesh
敌人（低模）     12 mesh
```

## 二、服务端还在用四款车白名单

```js
// 旧代码
const chassis = ['balanced', 'light', 'heavy', 'hunter'].includes(msg.chassis)
  ? msg.chassis : 'balanced';
```

客户端发 `'panther'` → 不在白名单 → 降级成 `'balanced'`。
虽然 `addPlayer` 里还会再归一化一次，功能上能兜住，但这是纯粹的隐式降级：
以后再加车体，忘了改这里，又会出现"选的 A 开出去是 B"。

改成 `normalizeChassisId(msg.chassis)`，一条路径，不再有白名单。

## 四、缓存：包里也改成 `no-cache` 了

你已经在服务端去掉了 300 秒，但如果直接部署我这个包，`server.mjs` 里的旧配置会把它改回去。
所以包里三处一起改：

| 位置 | 原来 | 现在 |
| --- | --- | --- |
| `server.mjs` `cacheHeaders()` | JS/CSS `max-age=300, must-revalidate` | 全部 `no-cache` |
| `deploy/nginx.conf` | 同上 | 全部 `no-cache` |
| `build.mjs` → `dist/_headers` | `/vendor/*` 一年 `immutable`、`/src/*` 600 秒 | 全部 `no-cache` |

`no-cache` **不是不缓存**，是"每次用之前回源验证"。文件没变就回 304（几十字节，无 body）。
ETag 用 `size + mtime` 派生，覆盖文件必变。

顺带说一个隐患：`dist/_headers` 里原来是
`/vendor/* → max-age=31536000, immutable`（一年、永不验证）。
如果哪天用静态托管部署，`three.module.js` 更新后老用户**一年**拿不到新的，
而且不会有任何报错，只表现成"改了代码没生效"。文件名没有 hash 就不该配 immutable。

### 如果你用 nginx

包里改了模板，但**不会自动改你服务器上的 `/etc/nginx/`**。确认一下：

```bash
grep -rn "max-age=300\|max-age=31536000" /etc/nginx/
```

有输出就说明还有地方在长缓存。

## 八、上一版（16）修的问题也在这个包里

简单复述，方便你对照：

1. **主炮打不出来 / 车不动** —— 世界会永久卡在 `lobby`。两条路径：倒计时到点调 `start()` 不看返回值却照样标记"已开局"；全员阵亡回大厅把 `autoStartT` 置 0 等人点一个局内看不见的按钮。现在用 `_startPending` 挂起重试，回大厅重新起 3 秒倒计时。
2. **视角乱跳** —— 联机相机先叠随机震屏再 `lookAt`，每帧视线被 `Math.random()` 掰一下。已改成先 `lookAt` 再叠双正弦平滑振荡。
3. **越打越卡** —— `world.start()` 不清场，重开后上一局残党叠在新一波上，`enemiesLeft` 永远清不到 0。已清场 + 回出生点满血。
4. **敌人血条看不清** —— 原尺寸 `2.24×0.14` 只有三四像素高。现在 `2.9×0.3` + 黑色描边。
