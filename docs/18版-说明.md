### 实现方式：一套缩放变量，不写死像素

设计稿是 1920 基准，直接写死像素会让 1366×768 的笔记本上「面板没变、浮动卡片挤到面板上」。
所以定义 `--s`（缩放系数），所有尺寸写成 `calc(设计稿数值 × var(--s))`：

```css
.menu-panel {
  width: calc(780px * var(--s, 1));
  border-radius: calc(35px * var(--s, 1));
  background: rgba(35, 41, 49, .80);
  border: 1px solid rgba(242, 202, 145, .80);
}
@media (max-width: 1440px) { .menu-overlay { --s: .84; } }
@media (max-height: 800px) { .menu-overlay { --s: .72; } }
```

**实测三档分辨率，1920 下与设计稿逐像素吻合：**

| 视口 | 面板 | 模式卡 | 输入框/按钮 | 榜单卡 | 键位卡 |
| --- | --- | --- | --- | --- | --- |
| 1920×1080 | **780×540** @570,270 | 156×88 ×3 | 280×50 | **176×385 @1721,27** | 176×216 @1721,838 |
| 1440×900 | 640×436 | 128×72 ×3 | 230×41 | 144×316 | 144×177 |
| 1366×768 | 562×385 | 112×63 ×3 | 202×36 | 隐藏 | 隐藏 |

面板高 540 而非设计稿的 520，多出的 20px 是那条「豹式」信息条（合并车型后新增，
设计稿里没有）。间距已按原稿比例收紧过：**初版实测 580 偏松，收紧后 540，位置 @570,270
与设计稿 @570,277 基本重合。**

> 1366 下浮动卡片隐藏是**有意的**：那时中央面板已经占到 562 宽，再塞 176 宽的两张卡必然重叠。

## 二、顺手修掉的 4 个问题

### 1. 媒体查询顺序把新版首页打乱了（实测踩到）

`styles.css` 有两处 `@media (max-width: 720px / 520px)` 写在文件**前段**，
里面留着按旧四宫格调过的规则：

```css
.chassis-card i { flex-direction: column; line-height: 1.35; }   /* 520px 处 */
```

新版首页样式在文件末尾，但这条 `column` 依然生效（媒体查询命中时就覆盖），
结果 1920 下「120 甲 / 15 速」被压成三列竖排，实测每段宽 46px、高 35px。
已在文件末尾补一段 `@media` 收尾，把首页相关规则全部覆盖回来。

### 2. 首页榜单 10 条被裁掉 3 条

行高原本写死 32px，10 行要 320px，但卡片扣掉标题条 60 和「你的名次」26 只剩约 290px，
实测第 8~10 行只剩半截。改成 `flex: 1 1 0` 按可用高度等分，10 行正好铺满。

### 3. 车体卡里的 emoji 图标会变成方块

原来车体卡用 `🐆` 当图标。在无 emoji 字体的环境（精简 Linux、部分 Windows Server、
部分安卓 WebView）会渲染成 ▯，看着像坏图。单卡态已改为纯文字标识，不再依赖 emoji。

### 4. 删掉 594 字符死样式

`.logo-line`、`.sub`、`.block-title`、`.start-panel` 在 HTML 里已经没有对应元素，
留着只会误导后来改样式的人。已删除。

## 六、已知限制

1. **设计稿只覆盖首页**。游戏内 HUD、强化卡、结算页、组队大厅仍是原版暗色描边风格。
   要统一的话需要设计稿里对应的画板 —— 现在文件里只有 `web 1920`（首页）和 `ico`（图标）两屏。
2. **首页榜单只显示前 10 条**。176×385 的卡片放不下更多；完整榜单（20 条 + 说明 + 名录）
   仍在点「排行榜」打开的弹窗里。
3. **1366 及以下不显示右上榜单与右下键位卡**。见上文，避免与中央面板重叠。
