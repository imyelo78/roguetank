## 二、旧站排行榜数据迁移

旧站 `roguetank.pages.dev` 的历史成绩现在可以并入新站。

### 工具

```bash
# 1. 抓旧站数据（扫日期区间，默认 2026-10-01 ~ 今天）
node tools/fetch-old-scores.mjs

# 2. 预览会导入什么
node tools/import-old-scores.mjs --dry-run

# 3. 真正写入
node tools/import-old-scores.mjs
```

### 为什么是离线导入，不是调接口

`functions/api/_lib/leaderboard.js` 的 `handlePost` 有一条防作弊：

```js
export const dateAllowed = (date) => date === todayKey(0) || date === todayKey(-1);
```

只收今天和昨天。历史成绩按它自己的日期提交必然被 `stale-date` 拒掉。
所以工具走**离线路径**：直接读 `.data/scores.json`，用**同一套**
`normalizeEntry` + `mergeEntry` 规则改存储，绕过 HTTP 层但不绕过规则。

### 已经抓到的数据

旧站只有 4 天有记录，共 8 条：

| 11-05 | 91 | 41,936 | 12 | 218 | — |
| 11-05 | selftest | 1 | 1 | 0 | — |

数据已存在 `tools/old-scores.json`，**随包一起交付**，不用你重新抓。

### 特性

- **幂等**：重复导入多少次结果都一样（同身份只留最高分，`t` 用原始时间戳）
- **保留原日期**：那天的榜就是那天的，不会全堆到今天
- **标记来源**：每条带 `importedFrom: 'roguetank.pages.dev'`
- **校验**：缺日期、分数非法、没名字的记录直接跳过
- **车体字段清空**：旧站的四款车（hunter/light/balanced/heavy）已不存在，
  写进去反而误导，`normalizeEntry` 会按白名单过滤掉

## 三、顺手修的一个 bug

切换「总排行榜」时，金色胶囊**不跟着走**，一直停在「今日排行」下面
（`.mb-tab[data-board="day"]::before` 写死了）。现在改成 `.mb-tab.sel::before`，
跟随选中态。设计稿只画了今日态，总榜态按同一规格平移。

## 五、你需要做的

1. 覆盖静态文件（`dist/` 下 `index.html`、`styles.css`、`src/`、`vendor/`）
2. 跑导入工具把旧站数据并进去：
   ```bash
   node tools/import-old-scores.mjs --dry-run   # 先看
   node tools/import-old-scores.mjs             # 再写
   ```
   `tools/old-scores.json` 已在包里，不用联网抓。

> 注意：导入工具改的是**服务器上的** `.data/scores.json`，要在部署目录下跑，
> 不是在你本机跑。跑完刷新首页就能看到那 8 条。
