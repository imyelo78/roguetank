# styles.css 设计说明

> `styles.css` 中较长的注释全文收录于此，CSS 里只保留 `/* [编号] 摘要 */`。
> 改样式前先按编号查这里，多数规则背后都有实测数据或踩过的坑。
> 编号与 CSS 里的 `[n]` 一一对应。
## [1] html, body

```
高度用 dvh，不用 %：手机上 100% 走的是 layout viewport（地址栏隐藏时的高度），
地址栏一露出来，页面底部连同 HUD、摇杆、选卡按钮一起被推到屏幕外。
100dvh 跟随"当前真正能看见的高度"，地址栏伸缩时自己会重排。
上面那行 100% 是给不支持 dvh 的老浏览器的退路。
```

## [2] .terrain-chip

```
地表指示：脚下是什么地形、跑得动跑不动。
   位置放在 WAVE 正下方，是玩家视野的落点区（瞄具在中间），
   不用抬眼看也能瞥到 —— 沼泽里被追时要靠它做决定。
```

```

## [4] .boss-bar

```
挪到左上角、挂在小地图右边。

原来在 top:104px / 水平居中 / 宽 560px —— 那正是玩家盯着瞄炮的正前方，
Boss 一露头，屏幕中上部横着一条 560px 的血条，弹道、护盾、小怪全被糊住。
血条只需要"看一眼知道还剩几成"，不需要占据视野带。

左边距 = 小地图左边距 + 小地图宽度 + 26px（12 是小地图自身的 padding/边框，
14 是间隙）。--map-size 由 Game.js 按窗口高度算好写进 :root，
因为小地图尺寸是 JS 动态定的，CSS 猜不出来。
```

## [5] （说明）

## [7] .minimap-wrap

```
左边距 = 上边距，且整体再往左上收一档（原来是 22 / 18，看着像贴歪了）。
不能一个写 22px + inset-left、一个写 18px + inset-top：横屏手机的
safe-area-inset-left 是刘海留白（~44px），而 inset-top 一般是 0，
于是左边距凭空比上边距宽一倍——玩家看到的就是"小地图没贴到角上"。
横屏时左侧安全区在这里没用（刘海在左边竖直中段，左上角碰不到），
所以下面 @media (orientation: landscape) 里直接不吃它。
```

## [8] .overlay

```
overlay 用 100dvh + 可滚动：
- 高度跟着 dvh 走，地址栏在不在都不会把面板顶出屏幕；
- 内容比屏幕高时（手机横屏选卡、结算面板）允许滚动，而不是上下各裁一半；
- 居中靠子元素的 margin:auto，而不是 align-items:center ——
  后者在内容溢出时会把顶部裁掉且滚不上去，这是 flex 居中的老坑。
```

## [9] .key-help

## [12] @media (max-height: 560px)

```
横屏手机的可用高度常年在 320~400px（再减掉地址栏），而宽度 800+ 会走三列布局，
于是「三列大卡」的总高顶出屏幕，上下各被裁一截 —— 这就是选卡在手机上"展不全"的原因。
这里按高度而不是宽度做压缩：横屏不缺横向空间，缺的是纵向。
```

## [13] .card

```
竖排卡用显式 grid 区域，不能靠自动放置：

   ==========================================================================
```

## [25] .key-help-list li > span

```
说明文字贴面板右沿（设计稿"行驶/瞄准/开炮"右沿都在 x=169，
   "切换解锁过的武器"更长，从 73 起、右沿同样 169）。
   ⚠ 两个坑，都踩过：
     1) 不能用 margin-left:auto —— 绝对定位元素上的 auto 边距会把它推出容器；

        也就是面板左边画布外。所以 li 必须是 static，让绝对定位落到 .key-help 上。
```

## [33] .hud-peek

```
==========================================================================
   手机端极简 HUD
   ---------------------------------------------------------------------------
   起因是实测截图：844×390 的横屏手机，去掉地址栏后可用高度 300 出头，
   而顶栏（装甲 + 波次 + 击杀得分）+ 中央大字 + 底部武器条 + 小地图加起来
   吃掉了上半屏 —— 敌人从上方压过来的时候，正好被这些面板挡个正着。

   继续"整体再缩一档"没用（缩到 8px 也还是挡），所以改成分层：

   · 常显（活着必需）：装甲条、波次微标、换弹 / 热量条、小地图、BOSS 血条
   · 收起（点右上「战况」展开 5 秒）：击杀得分、地形、挑战词条、
     强化图标、武器名与类型、联机房间码

   收起用 opacity + transform / max-height，不用 display:none ——
   后者只能硬闪，前者有 0.26s 过渡，展开时不会"啪"地跳出来。
   全部规则挂在 body.is-touch 下（HUD.bind 里判定 pointer: coarse 或
   maxTouchPoints > 0），桌面端一条都不生效，HUD 与 r34 完全一致。

   状态类刻意叫 peek-on 而不是 hud-peek：后者是胶囊按钮自己的类，而胶囊的
   基础规则里有 display:none —— 状态类要是也叫 hud-peek，#app 一挂上就被
   那条规则 display:none，整个界面直接消失（踩过一次）。
   ==========================================================================
```

## [38] .hud-pause

```
==========================================================================
   暂停 / 退出（单人局）
   ---------------------------------------------------------------------------
   联机不能暂停：世界在服务端跑，你停了队友不停 —— 所以按钮只挂单人局，
   Game.start() 时显示，进群狼共舞 / 结算 / 退回菜单时收起。

   按钮落点：波次胶囊右侧的空白带上（top 20 / 50% + 47px）。
