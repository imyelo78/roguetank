# 升级说明 r30 · 现状总结与可玩性方向

> 基线：`v1.0` / BUILD `r29` / 协议 3 / 线上 `https://roguetank.i1978.com`
> 本文只做记录与方案，**没有修改任何游戏代码**。
> 目的：把"现在这局游戏是什么样"写清楚，再列出下一版该动哪里。

---

## 一、这游戏现在是什么

3D 坦克肉鸽，Three.js，浏览器直接玩。三个入口：

| 模式 | 状态 | 说明 |
|---|---|---|
| 无尽冲锋 | 可用 | 单人，波次推进，死亡即结束 |
| 群狼共舞 | 可用 | 最多 4 人联机，服务端权威模拟，倒地可救 |
| 经典战役 | 未开放 | 菜单里是灰的 |

每局开局随机一条"挑战词条"（4 选 1），今日/总排行榜走每日种子。

部署：腾讯云 ECS + Nginx + Let's Encrypt，Node 单进程跑静态 + WebSocket，端口 5173（本地）。

---

## 二、一局是怎么推进的

1. 选车体（当前只有「豹式」一款）、填呼号、出击。
2. 第 N 波：按公式生成敌人 → 全部清掉 → 停 3 秒 → 发升级卡 → 下一波。
3. 第 **5 / 10 / 15…** 波是 Boss 波，**破城者 / 棱镜**交替。
4. 第 **3 / 8 / 13…** 波是精英波（2 辆，13 波后 3 辆）。
5. 单人第 **3 / 6 / 9…** 波清完后可以进军械库换主炮（联机未开放）。
6. 每波清完抽 3 张卡（12 秒，超时自动选第一张）。
7. 单人：血归零即结束。联机：血归零倒地，队友贴近 3 秒拉起；全员倒地才失败。
8. 没有终点波，一直往上打，分数进排行榜。

## 四、为什么"开着车一直跑、边跑边打"就能过关（核心诊断）

这不是错觉，是几套机制叠出来的结果。按影响从大到小：

### 1) 玩家比敌人快

- 玩家 **15 m/s**；小兵 9.1~13，Boss 7.2/9.2。
- 只有无人机（速度 ×1.9）追得上，但它只有 0.3× 血量，且玩家炮塔是**瞬间对准**， approaching 阶段就会被点掉。
- 结论：直线拉开距离 = 永久安全。

### 2) 敌人开火的窗口很窄

单人状态机（`src/Enemy.js:340`）：

- 距离 < 16m 且有视线 → 才进 `attack` 状态、才会开火；
- 距离 > 16m，或视线被建筑挡住 → `chase` / `flank`，**全程不开火**。

联机（`src/core/world.js:748`）：

- 射程内 + 炮塔弧长 <1.2m 就开火，不看状态；
- 但移动时基本打不中（见下条）。

### 3) 普通敌人没有提前量，跑起来就是必空

- 除 Boss 外，所有敌人的炮弹都朝"你**现在**的位置"飞（`src/Enemy.js:402`、`src/core/world.js:754`）。
- 弹速 42~55，18 米要飞 0.33~0.43 秒；你 15 m/s 横移，这期间挪 5~6.5 米，而命中半径只有 1.45 米。
- 数学上命中率≈0。**只有 Boss 有拦截解算**（`src/Enemy.js:596`、`src/core/world.js:596`）。
- 也就是说：会算提前量的只有两只 Boss，其余全部可以被"匀速横移"白嫖。

### 4) 炮塔全向 + 瞬间对准，逃跑没有代价

- 车体朝哪不影响炮口，鼠标指哪打哪，转向和移动完全解耦。
- 于是"背身逃跑 + 回头开火"是零成本的，不需要停下来、不需要把车头摆正。
- 这是"边跑边打"能成立的**最关键一条**。传统坦克游戏里"车头/炮塔朝向"的取舍在这里完全不存在。

### 5) 开火没有资源约束

- 除激光外没有弹药、没有过热、没有换弹；射击没有移速惩罚。
- 停下来打和跑着打的输出完全一样，那当然选跑。

### 6) 地图大、没有边界压力

- 200×200 的场地，Boss 和追兵很容易被甩开。
- 没有任何"缩圈 / 风暴 / 时间压力 / 资源点"逼你留在某个区域。

### 7) 波次按"清完"推进，拖时间没有惩罚

- 不打完不会刷新下一波，也没有倒计时增援。
- 于是"绕圈磨"是严格占优策略：风险更低、收益一样。

### 8) 敌人成长慢于玩家

- 敌人血量**线性** +14/波，速度第 8 波封顶。
- 玩家伤害是**乘算**（伤害 ×1.22^5、射速 ×1.18^4、双联、穿透、爆炸…）。
- 前 5 波玩家 DPS 约 65，第 10 波小兵 195 血需要 3 秒；到第 15 波卡成型后，清怪速度反而变快。
- 曲线是"先难后易"，与肉鸽该有的"越来越紧张"相反。

### 9) 回血过于慷慨

- 单人：清波 +6 + 纳米 +36 + 击杀回血；联机：清波 +25% 最大血。
- 跑两圈回来血又满了，"受伤"不构成压力。

### 10) 联机比单人更简单

- 受击 ×0.7、倒地能救、敌人血量只 ×√n，4 个人火力是线性叠加。
- 人数越多，"总输出 / 总承伤"越高 → 4 人房是全场最轻松的模式。

### 一句话总结

> 玩家的**机动性**（15 m/s + 全向瞬间炮塔 + 无射击成本）远高于敌人的**命中能力**（无提前量 + 16m 开火窗口 + 封顶 13 m/s），中间没有任何机制要求玩家承担"停下来"的风险，所以最优解必然是跑。

## 五、已确认的功能缺陷（和平衡分开，属于 bug）

这些是上一轮核验时确认过、目前还没修的：

1. **联机双联炮无效**：服务端 `_playerFire` 永远只发 1 发，不读 `stats.multishot`（`src/core/world.js:548`）。单机正常。
2. **联机破城者三联炮 / 棱镜三连点射无效**：服务端敌人开火只 push 1 发，没有 Boss 分支（`src/core/world.js:751`）。单机正常（`src/Enemy.js:592,610`）。
3. **联机大部分成长卡空转**：`syncedStats` 同步了 `damageMul / fireRateMul / bulletSpeedMul / splashDamageMul / multishot / pierce / explosive / waveHeal`，但服务端一个都没读。
   - 空转的卡：火力强化、快速装填、双联炮组、穿甲弹芯、高爆弹头、电磁轨道、过载核心、反应装甲、壁垒协议、纳米修复。
   - 真正生效的只有：涡轮增压、复合装甲、战地维修。
4. 联机军械库未开放（只有突击炮）。
5. `v1.0` 缺 `.gitignore`（`node_modules/`、`dist/` 等没被忽略）。

## 六、升级方向（按"改动小、体感明显"排序）

### A. 让"跑"有代价（最高性价比）

1. **移动射击惩罚**：移动中散布 ×2~3 或伤害 -20%，停下 0.3 秒后恢复。只改 `resolveWeapon` + 开火调用点，风险最低。
2. **炮塔惯性**：把豹式的"瞬间对准"改成 120~180°/s 的转速。车体转向不再白送炮口方向，逃跑时瞄准会明显变钝。
3. **履带/悬挂**：连续转向或高速移动时炮口抖动，进一步降低"跑打"精度。

### B. 让敌人能真正威胁到移动目标

4. **普通敌人也加提前量**，但给不同兵种不同精度（小兵 0.3、精英 0.6、炮台 0.8），而不是只有 Boss 会算。
5. **区域封锁**：炮台/精英改成"预警圈 + 落点爆炸"，逼玩家离开当前路线（不是点射，是封路）。
6. **包抄与拦截**：给一部分敌人"预判你的逃跑方向、切到前面"的行为，而不是直线追尾。
7. **无人机成群**：现在是单只 0.3× 血，改成 3~5 只小编队，迫使玩家停下来处理。

### C. 加入"必须站住 / 必须守"的目标

8. **据点占领**：波次中随机刷一个需要停留占领的区域，占满才刷下一波。
9. **护送 / 护送失败**：护一辆补给车到指定点，敌人优先打它。
10. **限时清波**：超过 N 秒没清完，敌人增援/强化，直接否掉"绕圈磨"。
11. **资源点**：地图上刷弹药/修理，必须靠近拾取，制造"必须冒险"的动机。

### D. 给逃跑加硬成本

12. **缩圈 / 电磁风暴**：每波安全区缩小，或者场地边缘持续掉血。
13. **体力条**：连续高速移动消耗体力，耗尽降速，逼迫"跑—停—打"的节奏。
14. **缩小地图**：200×200 → 140×140，减少拉扯空间（改动最小但很有效）。

### E. 成长曲线与卡池

15. **敌人血量改分段指数**（如每 5 波 ×1.6），或给敌人加"护甲/抗性"维度，避免玩家乘算碾压。
16. **卡池互斥取舍**：伤害系和机动系不能同时拿满；或加"负面词条"（拿伤害就降移速）。
17. **Boss 反风筝**：拉人、定身、封路、视野压制，而不是单纯加速。

### F. 先把 bug 修了

18. 联机多联装、Boss 连发、死卡（见第五节）。否则任何平衡调整在联机里都不成立。

## 七、建议的实施顺序

| 优先级 | 内容 | 预期效果 | 风险 |
